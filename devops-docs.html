Pixmeal Backend DevOps Setup

Complete documentation for containerization, deployment, and CI/CD workflows

Overview

The Pixmeal Backend uses a modern DevOps stack built on Docker containers, providing consistent environments across development and production. The setup includes a Node.js NestJS API, PostgreSQL database, and automated testing and deployment pipelines.

Docker Configuration

Multi-stage Dockerfile

The project uses a multi-stage Docker build to optimize image size:

FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
COPY prisma ./prisma/
RUN npm ci
COPY . .
RUN npx prisma generate
RUN npm run build

FROM node:20-alpine
WORKDIR /app
COPY --from=builder /app/dist ./dist
COPY --from=builder /app/node_modules ./node_modules
COPY --from=builder /app/package.json ./package.json
COPY --from=builder /app/prisma ./prisma
ENV NODE_ENV=production
EXPOSE 3000
CMD ["npm", "run", "start:prod"]
  • Builder stage: Installs dependencies, generates Prisma client, builds TypeScript
  • Production stage: Runs only the compiled output, keeping image minimal (~150MB)
  • Node.js 20 Alpine base for security and size

Task Automation (Taskfile.yml)

The project uses Task (taskfile.dev) as a cross-platform task runner. It's more portable than Makefiles and works on Windows, macOS, and Linux.

Available Tasks

task install
Install npm dependencies using npm ci (deterministic)
task build
Build Docker images using docker compose build
task lint
Run ESLint on the src directory
task test
Run Jest test suite
task ci
Run lint → test → build sequence (full CI pipeline)
task deploy
Deploy stack locally with docker compose up -d
task logs
Show logs (set SERVICE=app to filter)
task restart
Restart all services
task stop
Stop the stack (preserve volumes)
task clean
Remove containers AND volumes (WARNING: deletes data)
task push
Build and push image to registry with git hash tag
task deploy:remote
Deploy to remote server via SSH

CI/CD Pipeline

Local Development Workflow

# Install deps and start in development
task install
task deploy

# View logs
task logs

# Stop when done
task stop

CI Validation

# Run full CI pipeline
task ci

This runs: ESLint → Jest → Docker Build

Production Deployment

# Build and tag with commit hash
task push

# Deploy to remote server
task deploy:remote
